第二步：如何花 3 分钟完全免费获取上面的钥匙？

方式 A：用 JSONBin.io（最简单，不用敲任何代码）
  1. 打开 https://jsonbin.io 用 GitHub 或谷歌账号免费登录。
  2. 在首页编辑器里随便写一个 {"init": true}，点击 Save / Create Bin，复制生成的 Bin ID（一串字母数字，填到上方“云端地址 / Bin ID”）。
  3. 点击左侧菜单 API Keys，复制你的 X-Master-Key，填到上方“访问密钥 API Key”，点保存就完成了！
方式 B：用 Supabase（专业级免费云数据库）
  1. 打开 https://supabase.com 免费创建一个新项目，在左侧 SQL Editor 运行下面这三行建表语句：
create table if not exists study_sync ( id text primary key, payload jsonb not null default '{}'::jsonb ); alter table study_sync enable row level security; create policy "allow_all_sync" on study_sync for all using (true) with check (true);
然后在 Supabase 的 Project Settings → API 中复制 Project URL 和 anon public key 填入上方即可。
